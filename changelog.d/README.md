# Changelog fragments

`CHANGES.rst` is generated by [towncrier](https://towncrier.readthedocs.io/);
never edit it by hand. Instead, add a file here in each pull request:

    changelog.d/<issue>.<type>.rst

`<type>` is one of `breaking`, `added`, `changed`, `fixed` or `removed`. Use
the issue or pull request number, or a short slug prefixed with `+` when the
change has neither:

    changelog.d/142.added.rst
    changelog.d/+offset-repr.breaking.rst

Write the entry as prose describing what changed for a user of the library.
At release time, `uv run towncrier build --version X.Y.Z` folds every fragment
into `CHANGES.rst` and removes them.
